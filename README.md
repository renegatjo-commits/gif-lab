# GIF Lab

Редактор GIF для браузера и встраивания на форум. Доступ без регистрации и входа в ChatGPT.

- Загрузка GIF с устройства, перетаскиванием и по прямой ссылке.
- Изменение размера и обрезка рамкой или по координатам.
- Быстрые форматы: **125 × 100 горизонтальный**, **180 × 180**, **50 × 50** (ширина × высота).
- Чёрно-белый режим, цветовые фильтры и настройки яркости, контраста и насыщенности.
- Пакетная обработка до **50 GIF** с общими настройками, отдельными файлами и ZIP.
- Сохранение кадров, прозрачности и задержек анимации. Скорость и зацикливание можно изменить.

Файлы с устройства обрабатываются локально в браузере. Максимум 30 МиБ на исходную GIF, 1000 кадров, 60 млн пикселей во всех кадрах и 2048 px на сторону результата.

## Загрузка по ссылке

GitHub Pages размещает статические файлы. Импорт по ссылке работает, если хостинг изображения разрешает браузеру загружать GIF с другого сайта (CORS). Закрытые ссылки и хостинги с запретом CORS нужно скачать самостоятельно и загрузить через кнопку выбора файла. Редактор не передаёт GIF сторонним прокси.

## GitHub Pages

Готовая версия находится в **docs/**. В настройках репозитория откройте **Settings → Pages → Deploy from a branch → main → /docs → Save**.

## Вставка на форум

Для сообщения Rusff/MyBB с включённым HTML:

```html
[html]
<iframe src="https://renegatjo-commits.github.io/gif-lab/?embed=1" title="Редактор GIF" style="display:block;width:100%;height:1100px;border:0;border-radius:12px;" loading="lazy"></iframe>
[/html]
```

Для обычной HTML-страницы уберите `[html]` и `[/html]`. `?embed=1` скрывает вступление и сокращает шапку. Высоту iframe можно изменить. Если форум оборачивает HTML во фрейм с sandbox, во внешнем sandbox должны быть разрешены scripts, same-origin, forms и downloads. Если скачивание запрещено настройками форума, откройте редактор отдельной вкладкой.

## Разработка

Node.js 22+, pnpm 11:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
```

После изменений соберите `docs/` и добавьте обновлённые файлы в коммит. Все пути относительные: версия работает в подпапке GitHub Pages.

Зависимости React, Lucide, gifuct-js, gifenc, fflate и js-binary-schema-parser сопровождаются лицензиями в `public/licenses/` и `docs/licenses/`.
